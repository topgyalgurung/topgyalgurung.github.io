# topgyalgurung.github.io

Personal portfolio and blog.

## Local preview

This site uses Jekyll. **Live Server will not work** — it serves raw files and doesn't process `{% include %}` tags.

**Option 1** — Run the script:
```bash
chmod +x serve
./serve
```

**Option 2** — Manual:
```bash
bundle install    # Do this first if you get "command not found: jekyll"
bundle exec jekyll serve
```

Then open **http://localhost:4000**
